# content — 이 축의 콘텐츠 작업 폴더

`device-payment/` 는 **증거**를 관리하고, 여기는 그 증거로 만드는 **기사·키노트·영상**을
관리한다. 섞지 않는다 — 증거가 콘텐츠에 맞춰 움직이면 실증이 아니게 된다.

```
plan-2026-08-31.md   기획 — 축 넷 · 산출물 셋 · 촬영 목록 · 결정 필요
article/             기사 4편. 편마다 conti.md 먼저, 그 다음 원고(ko 정본 → en/ja/zh)
keynote/             슬라이드 원고
video/               컷 시퀀스 · 나레이션/자막 · 촬영 지시
assets/              다이어그램(🎨) · 터미널 캡처(🖥️) · 사진(📷)
```

## 규칙 셋

**콘티가 먼저다.** 글을 바로 쓰지 않는다. 컷 시퀀스 + 각 컷의 목적·본문 gist·비주얼 슬롯
(무엇 + 출처 태그)·자료를 먼저 세운다.

**실증만 싣는다.** 여기 들어가는 수치·화면·거절 문구는 전부 *실제로 돌려서* 나온 것이다.

**한 것을 쓴다.** 정확하게 쓰되, 안 한 것의 목록은 기사가 아니다 — 그 경계는 검증
문서(`../tests.md`·`../coverage.md`)가 진다. 콘텐츠는 거기서 가져다 **이야기를 한다.**
