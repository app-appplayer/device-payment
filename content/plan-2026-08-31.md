## 두 편이 서는 지점

각 편의 결정적 증거는 하나씩이다. 나머지 실행 결과는 저장소로 보낸다.

**1편** — 8초짜리 권한을 물리고 **아무것도 보내지 않은 채** 기다린다.

```
present  → accepted locker-demo-20s
open     → open
… 12초, 아무 입력 없음 …
open     → refused: authority expired
```

**2편** — 자판기를 얹는다. **검증 코드를 한 줄도 쓰지 않고** 같은 거절이 전부 선다.

```
자판기 — 같은 플랫폼, 같은 보장
  ok  서명 변조 거절     ok  남의 기기 거절
  ok  안 판 액션 거절    ok  재생 거절
```
